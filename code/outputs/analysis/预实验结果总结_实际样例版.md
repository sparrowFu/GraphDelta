# GraphDelta 预实验结果总结：结合数据集实际样例

日期：2026-10-22。分析对象：现有冻结 CLIP ViT-L/14 的 E1、E2、E3 输出。

## 一、总体结论

本轮得到三个主要发现：

1. **静态结构区分存在明显不均衡。** CLEVR 中颜色判断明显强于关系与绑定判断；SPAR 也呈现类似趋势，但自建样本有过滤问题，需要修正重跑。
2. **变化表示的规律因因素而异。** 环境变化的方向一致性最强；纹理较弱；大小与相机变化难以跨 context 保持共同方向。变化幅度大，不代表变化规律稳定。
3. **没有检出 CoGenT A/B 的整体难度差。** 但拆开具体组合后，发现跨条件稳定的形状相关难度，尤其换形题中的 cylinder 明显弱于 cube。

这些结果支持继续开展小规模受控结构编辑机制验证，尚未证明 GraphDelta 方法有效、视觉和文本的结构变化已经对齐，或这种变化规律能够迁移到未见组合。

> 阅读边界：以下 E1 题目来自实际导出的 JSONL，中文为原始 caption 的翻译。当前文件夹没有原始图片，也没有保存逐题预测，所以这些例子是“真实题目”，不是已确认的模型错例。E2、E3 的例子是实际 transition 或组合的分组统计，不能归属于某一张具体图片。

## 二、E1：模型能否区分正确与错误的结构描述？

### 2.1 实验怎样做

固定一张图片，提供正确描述 T+ 和错误描述 T−，比较图像与两条文本的匹配分数。只有 T+ 分数更高才算正确，平局记错。

二选一的随机水平为 50%。结果是七个固定 prompt 模板的正确率均值；每组 2,000 道题，不能把七倍模板预测当成独立样本。

### 2.2 真实颜色题：红色球还是绿色球？

图片 ID：`CLEVR_val_000004.png`。

| 标注 | 原始内容 | 中文解释 |
|---|---|---|
| T+ | `a small red rubber sphere` | 一个红色的小橡胶球 |
| T− | `a small green rubber sphere` | 一个绿色的小橡胶球 |

两个描述只改变颜色，模型需要判断图片中的对象究竟是红色还是绿色。

**这类颜色题整体准确率为 67.56%，95% CI 为 [65.78%, 69.38%]。** 模型具有一定颜色区分能力，但远未达到准确识别所有题目的程度。

来源：[实际题目，第 2002 行](D:/code/GraphDelta/code/outputs/tables/e1_items_clevr.jsonl:2002)。

### 2.3 真实绑定题：棕色属于圆柱，还是属于球？

图片 ID：`CLEVR_val_000000.png`。

| 标注 | 原始内容 | 中文解释 |
|---|---|---|
| T+ | `a brown cylinder and a purple sphere` | 一个棕色圆柱和一个紫色球 |
| T− | `a purple cylinder and a brown sphere` | 一个紫色圆柱和一个棕色球 |

两条描述包含完全相同的概念：棕色、紫色、圆柱、球。唯一改变的是颜色与物体的对应关系：

```text
正确：棕色 → 圆柱，紫色 → 球
错误：紫色 → 圆柱，棕色 → 球
```

**这类绑定题整体准确率为 50.76%，95% CI 为 [48.81%, 52.64%]，接近随机水平。**

颜色题与绑定题相差 16.81 个百分点，差值 CI 为 [14.09, 19.53] 个百分点。这是本轮最明确的结构不均衡证据之一：知道有哪些颜色和物体，还不足以判断颜色究竟属于哪个物体。

来源：[实际题目，第 10001 行](D:/code/GraphDelta/code/outputs/tables/e1_items_clevr.jsonl:10001)、[组间差值](D:/code/GraphDelta/code/outputs/tables/e1_factor_gaps.csv)。

### 2.4 真实关系题：在前面，还是在后面？

图片 ID：`CLEVR_val_000006.png`。

| 标注 | 原始内容 |
|---|---|
| T+ | `a large blue metal cube is behind a small gray rubber sphere` |
| T− | `a large blue metal cube is in front of a small gray rubber sphere` |

中文含义：大蓝色金属立方体在小灰色橡胶球的后面／前面。

物体、颜色、大小和材质都没有改变，只有前后关系反转。

**这类关系题整体准确率为 51.59%，95% CI 为 [49.54%, 53.57%]，同样接近随机水平。** 颜色题比关系题高 15.98 个百分点，差值 CI 为 [13.28, 18.94] 个百分点。

来源：[实际题目，第 8001 行](D:/code/GraphDelta/code/outputs/tables/e1_items_clevr.jsonl:8001)。

即“熊在斑马下面”与“斑马在熊下面”。动物和“下面”这个关系词全部保留，只交换主客体角色。

### 2.6 E1 整体结果及结论

| 数据集 | 判断内容 | 准确率 |
|---|---|---:|
| CLEVR | 对象形状 | 56.08% |
| CLEVR | 颜色 | 67.56% |
| CLEVR | 大小 | 53.01% |
| CLEVR | 材质 | 55.66% |
| CLEVR | 关系 | 51.59% |
| CLEVR | 绑定 | 50.76% |
| SPAR 自建 | 动物身份／存在性，代码中名为 scene | 89.66% |
| SPAR 自建 | 位置 | 39.82% |
| SPAR 自建 | 属性绑定 | 51.30% |
| SPAR 自建 | 关系 | 46.63% |

SPAR 自建结果存在约 3.1%–3.4% 的正例包含 `blank` 空对象的问题，需要修正后重跑。此外，位置题有明显模板与方向分布影响，不能把低于 50% 直接解释为空间理解反转。

官方样式 hard-negative 评估中，位置准确率为 47.66%–50.00%，关系为 49.95%–53.20%，属性绑定为 53.50%–55.70%。这些是有无背景文本等不同设置的结果范围，不是置信区间，也不能与自建协议直接混算。

**E1 支持的结论：当前 CLIP 图文匹配在关系和绑定利用上较弱，颜色与结构任务之间存在明确差距。**

对象、大小、材质本身也没有很高，所以不能进一步断言“原子概念都已经识别得很好，只有组合出了问题”。E1 也无法单独确定问题来自视觉编码、文本编码还是匹配方式。

## 三、E2：同一种变化，能否产生共同的表示变化方向？

### 3.1 实验怎样做

从 PUG: Animals 已有图片中配对，固定其他 metadata，只改变环境、动物纹理、大小或相机中的一个因素，计算：

```text
Δ = 变化后的表示 − 变化前的表示
```

观察两个不同指标：

- **变化幅度：**表示移动了多远，是否大于当前增强基线。
- **方向一致性：**同一种具体变化发生在不同 context 中，Δ 是否指向相近方向。

这里的方向相似度是不同 Δ 之间的余弦，不是变化前后两张图片的相似度。相似度越接近 1，共同方向越强；接近 0，则缺少一致方向。context 指除被测因素外其余 metadata 的组合。

### 3.2 实际 transition 举例

下表的幅度与相似度统一使用 L2 归一化表示空间：

| 实际变化 | context 数 | Δ 平均幅度 | Δ 方向相似度 |
|---|---:|---:|---:|
| TokyoDay → TokyoNight | 9 | 0.4551 | 0.5392 |
| Hallway → TrashRoom | 8 | 0.4762 | 0.1406 |
| 动物纹理 Asphalt → Grass | 4,986 | 0.2935 | 0.1718 |
| small → large | 10,091 | 0.3301 | 0.0846 |
| medium → large | 9,890 | 0.2403 | 0.0297 |
| camera 225° → 315° | 4,938 | 0.3869 | 0.0022 |

当前视觉增强基线的平均 Δ 幅度为 **0.2951**。

这些实际例子说明：

1. **东京白天到夜晚：**不同 context 中有较强共同方向。
2. **走廊到垃圾房：**幅度与东京昼夜变化接近，但方向一致性弱得多。幅度接近不代表规律接近。
3. **相机 225° 到 315°：**表示移动幅度不小，但跨 context 几乎没有共同方向。变化大不等于方向稳定。
4. **small 到 large 与 medium 到 large：**前者平均幅度高于增强基线，后者低于。size 因素的总体均值不能代替每个具体 transition 的结论。

环境单个 transition 只有少量 context，表中没有逐 transition CI，因此不应把某两个条目的大小关系当成已确认的稳定差异。这里也没有具体动物／环境的逐 pair 清单，不能据此编造某张动物图像的案例。

来源：[东京昼夜，第 2009 行](D:/code/GraphDelta/code/outputs/tables/e2_transition_stats.csv:2009)、[走廊到垃圾房，第 1460 行](D:/code/GraphDelta/code/outputs/tables/e2_transition_stats.csv:1460)、[动物纹理，第 2028 行](D:/code/GraphDelta/code/outputs/tables/e2_transition_stats.csv:2028)、[大小，第 2024 行](D:/code/GraphDelta/code/outputs/tables/e2_transition_stats.csv:2024)、[相机，第 7 行](D:/code/GraphDelta/code/outputs/tables/e2_transition_stats.csv:7)。

### 3.3 E2 整体结果及结论

| 因素 | raw 平均幅度／视觉增强基线 | 同 transition 跨 context 相似度 z | 解释 |
|---|---:|---:|---|
| environment | 2.48 倍 | 0.6433 | 幅度与共同方向均较强 |
| texture | 1.00 倍 | 0.1155 | 有一定方向规律，幅度约等于增强基线 |
| size | 0.93 倍 | 0.0548 | 总体幅度较小，跨 context 一致性弱 |
| camera | 1.40 倍 | 0.0153 | 幅度较大，共同方向很弱 |

raw 指归一化前表示，z 指 L2 归一化后表示，不是 z-score。两种空间的主要趋势一致。

当前增强函数将裁剪比例同时乘在宽高上，配置 0.85–1.0 实际对应最低约 72.25% 保留面积，而非 85%。该增强可能影响尺度语义，需拆分 JPEG-only 和裁剪对照后复核大小变化结论。

**E2 支持的结论：原始表示中存在部分可重复的单因素变化规律，但强弱高度依赖因素及具体 transition。** 环境变化的强结果不能直接推广到关系反转或绑定交换；本轮也没有测量同一语义编辑的视觉 Delta 与文本 Delta 是否一致。

来源：[E2 主表](D:/code/GraphDelta/code/outputs/tables/e2_delta_stats.csv)、[增强实现](D:/code/GraphDelta/code/src/features/delta.py:13)。

## 四、E3：总体 A/B 接近，是否代表具体组合也一样容易？

### 4.1 实验怎样做

在 CoGenT A、B 两组颜色—形状组合条件下，使用正确的颜色—形状描述，并构造换色或换形负例。负例对应的组合须在整张图中不存在。

例如，换形题保持颜色、改变描述中的形状。代码允许在 A 的红色圆柱题中选红色立方体作为负例，但也可能选符合条件的红色球。当前输出没有逐题负例记录，因此不能断言某一道实际抽到了哪个负例。

### 4.2 实际红色、黄色组合的表现

| 条件 | 正例组合 | 换形题 n | 换形题准确率 |
|---|---|---:|---:|
| A | red cylinder，红色圆柱 | 161 | 16.15% |
| B | red cube，红色立方体 | 177 | 91.69% |
| A | yellow cube，黄色立方体 | 182 | 97.96% |
| B | yellow cylinder，黄色圆柱 | 190 | 28.12% |

红色组合从 A 的圆柱变为 B 的立方体，准确率大幅上升；黄色组合从 A 的立方体变为 B 的圆柱，准确率大幅下降。因此，A 不是所有组合都容易，B 也不是所有组合都困难。

这些是组合分组统计，不是同一图片改变颜色或形状后的前后对照，也没有保存形状子组的按图聚类 CI。

来源：[红色圆柱，第 22 行](D:/code/GraphDelta/code/outputs/tables/e3_cogent_by_combo.csv:22)、[红色立方体，第 70 行](D:/code/GraphDelta/code/outputs/tables/e3_cogent_by_combo.csv:70)、[黄色立方体，第 25 行](D:/code/GraphDelta/code/outputs/tables/e3_cogent_by_combo.csv:25)、[黄色圆柱，第 73 行](D:/code/GraphDelta/code/outputs/tables/e3_cogent_by_combo.csv:73)。

### 4.3 E3 整体结果及结论

| 对象组 | A 题型等权准确率 | B 题型等权准确率 | A−B，95% CI |
|---|---:|---:|---:|
| cube／cylinder | 65.66% | 66.31% | −0.65pp [−2.65, +1.42] |
| sphere 对照 | 73.73% | 73.47% | +0.26pp [−1.66, +2.28] |

没有检出整体 A/B 难度不对称，也不能据此认定 A/B 等价。

拆开正例形状后，换形题 cube 在 A/B 分别为 87.93%／88.35%，cylinder 为 33.20%／33.40%。这种跨条件稳定的形状相关难度，比整体 A/B 差异更突出，但其原因仍可能包括形状识别、文本偏好和负例构成。

**E3 支持的结论：整体条件均值掩盖了具体组合与形状的差异；本轮没有支持预期的 A/B 整体不对称。** 冻结模型没有在本研究中 train-on-A，不能把这些结果解释为已见到未见组合的泛化成绩。

来源：[主差值表](D:/code/GraphDelta/code/outputs/tables/e3_difficulty_gap.csv)、[组合表](D:/code/GraphDelta/code/outputs/tables/e3_cogent_by_combo.csv)。

## 五、这些结果对 GraphDelta 意味着什么？

| 研究命题 | 当前证据状态 |
|---|---|
| 当前模型在结构区分上存在不均衡 | 有较明确支持，尤其 CLEVR 颜色相对关系／绑定的优势 |
| 表示中存在可重复变化规律 | 部分支持，环境最强，其他因素较弱 |
| 关系／绑定失败由结构变化响应不足导致 | 尚未验证，E1 与 E2 不能直接建立因果联系 |
| 结构编辑的视觉 Delta 与文本 Delta 一致 | 尚未验证 |
| context-conditioned 模型优于固定 Delta | 有研究动机，尚未验证优越性 |
| 学习 Delta 能改善未见组合迁移 | 尚未验证 |

对[完整预实验方案](D:/code/GraphDelta/GraphDelta_完整预实验方案_统一修订版.md)，本轮结果帮助确定了重点：E1 是主要问题证据，E2 应区分幅度与方向，E3 需要控制形状和负例，而不应只盯住 A/B 总分。它更接近方案 §71 的情况 C，同时保留 E1 与部分 E2 的正证据。

对[研究框架](D:/code/GraphDelta/GraphDelta_研究框架_统一修订版.md)，当前结果增强了研究动机，但跨模态一致性、context 建模收益和未见组合迁移仍应保留为待检验假设。E1/E2/E3 不必全部出现预期正结果，才值得做小规模第二阶段验证；进入完整 GraphDelta 训练则需要更强的机制证据。

## 六、下一步应补上的实验

当前模型在绑定交换题上整体接近随机。以下真实题目展示了下一步要进一步研究的变化：

```text
棕色圆柱 + 紫色球
紫色圆柱 + 棕色球
```

下一步需要让图片真正发生这种受控绑定交换，并回答：

1. 视觉表示是否清楚反映了绑定交换？
2. 文本发生同样交换时，文本 Delta 是否与视觉 Delta 对应？
3. 换成其他颜色、物体或未参与拟合的 context，这种对应是否保持？

执行优先级为：

1. 修复 SPAR blank 过滤，复核 nuisance 裁剪定义，保存逐题分数与具体负例。
2. 补 seed 0/1/2 的独立采样结果；配置列出三个 seed 不等于已完成三次运行。
3. 开展小规模 Controlled Edit：Color Change 作正控制，Binding Swap／Relation Change 作核心问题，分别检验编辑可识别性、跨模态一致性和 held-out context 迁移。
4. 机制证据成立后，再比较完整 GraphDelta 与固定 Delta、hard-negative、状态结构监督等基线。

第一阶段为研究问题提供了具体依据；第二阶段负责检验结构变化机制；第三阶段才检验 GraphDelta 是否带来方法收益。
