0. 一页结论

  1. 数据可信：9 个 run × 5 个实验全部 success；pos_value 配额精确等额（如 size 1000/1000、relation 500×4）；position 视角翻转比例恰 0.500；"恒选某词"策略期望准确率恰 1/k；90 个 run×factor 的汇总表可由逐题数据重算（accuracy 偏差 ≤2.2e-16）。
  2. E1 三类因素：
    • 真辨别：scene 0.749/0.887/0.990、color 0.683–0.705、object 0.575–0.639（cube 侧 0.88–0.92 / cylinder 侧 0.14–0.38，值严重不均）；
    • 纯词偏好、辨别≈0：size（三模型分侧 ≈1.000/≈0.000，总体恰 0.500）、clevr/relation（vitb32 恒选含 left 的句 .996/.005、vitl14 恒选含 right .991/.009、siglip2 弱偏好 left .823/.173）、pug_spar/position（总体 0.489–0.503，above 侧普遍高于 below 侧）；

  3. 2. E1 静态结构诊断

2.1 读数方法

  • 每因素 target=2000 条 2AFC（image→text，7 模板均值，平局记错），正例一侧取值 pos_value 分层等额抽取；
  • 总体 accuracy = 干净辨别指标（恒选某词期望恰 0.5，总体超出 0.5 的部分只能来自辨别）；
  • 分侧准确率之差 = 词偏好强度；一侧趋近 1、另一侧趋近 0 即"恒选某词"的直接证据；
  • 二值因素可分解：总体 ≈ 0.5 + 辨别项 ± 偏好/2；
  • 免疫因素（binding / attribute / spar relation：正负例词集相同）总体即干净读数。

逐因素读法：

  • size：纯词偏好。三模型全部恒选含 small 的描述（large 侧 ≈0、small 侧 ≈1），总体恰 0.500。辨别为零。
  • clevr/relation：纯词偏好。vitb32 恒选含 left 的句子、vitl14 恒选含 right、siglip2 弱偏好 left；front/behind 也同向不对称（vitl14 front .730 / behind .324）。总体 0.503–0.513 的微小偏离全部可由偏好不对称解释。
  • pug_spar/position：无辨别。三模型 above 侧 > below 侧（vitl14 差 .58），vitb32 left .714 / right .256，但四值等额下总体都在 0.5 附近。
  • object：辨别 + 偏好混合。cube 侧 0.88–0.92、cylinder 侧 0.14–0.38、sphere 侧居中；负例词在各侧对称出现，纯偏好会给 0.5，总体 0.58–0.64 说明有真实成分，但各词难度严重不均。
  • material：模型间质不同。vitl14 分侧差 0.18、总体 0.575，真辨别为主；vitb32 分侧差 0.78、总体 0.527，偏好为主加少量辨别；siglip2 分侧差 0.55、总体 0.598，介于两者。
  • color：真实但严重不均。每模型都有接近随机的颜色（vitb32 brown .516、vitl14 green .446、siglip2 brown .205）和很高的颜色（cyan .93+）。
  • scene：真辨别（回退抽样，恒选某词上界 0.042）：0.749 / 0.887 / 0.990。
  • binding：免疫、干净零辨别。9/9 含 0.5。全局零样本打分未能利用绑定信息——SigLIP2 身份近乎满分（scene .990）时绑定仍 ≈0.51，身份辨别强不自动带来绑定辨别。
  • 两个显著反向：vitb32 attribute 0.399（3/3 CI<0.5）、vitl14 spar relation 0.456（3/3 CI<0.5）。免疫因素无词偏好可混入，低于 0.5 是系统性反向偏好（模型更偏好换绑/换主客的错误描述），机制待查。
  • 模板方差（template_variance 列）量级 2e-5 – 1.3e-3，最大的 siglip2 attribute 也不改变上述判定。

3. E2 单因素表示响应

3.1 指标与口径（直接对应 e2_delta_stats.csv 列）

  • transition similarity gap（z 空间）：同因素同转换跨 context 相似度 − 不同因素跨 context 相似度；CI>0 即"具体转换可复现"；
  • norm gap（raw/z）：‖Δ_factor‖ − ‖Δ_nuisance‖（nuisance = 同图确定性增强视图之差）；CI>0 即响应超出渲染扰动；
  • ratio = factor_over_nuisance_ratio，>1 即因素响应大于 nuisance；
  • 覆盖量取自 e2_transition_stats.csv 的 n_contexts 分布。

3.4 解读

  • environment 是唯一全面成立的因素：两个数据集、三个模型，transition gap 0.64–0.79 全部 CI>0，且范数差 CI>0、ratio 1.7–2.8。支持"具体环境转换跨 context 高度可复现"。
  • texture 数据集依赖：Animals 上 vitb32/siglip2 的范数差 CI 为负（响应小于 nuisance），ImageNet 上三模型都为正；tgap 两个数据集都为正但幅度小（0.11–0.35）。
  • size / camera 弱：tgap CI>0 但幅度 ≤0.15；size 在 Animals 的范数差三模型全负、ratio 0.61–0.96；camera 范数差符号随模型翻转。
  • 覆盖量警告：ImageNet environment 的 57.1% 转换只有 1 个 context——该数据集上"跨 context 可复现"的证据集中在其余 43% 的转换上，结论弱于 Animals。Animals environment 每转换平均 6.67 个 context，证据扎实。
  • 结论：支持"具体转换（尤其环境转换）有可复现的表示响应"，不支持"每个因素都有统一、可跨转换泛化的方向规律"。

第二阶段建议：以小规模受控编辑（Controlled Edit）验证为主——对 relation / binding 的失败直接检验"视觉 Δ 是否不足"与"打分是否不利用"两个假设；受控编辑设计应同时覆盖 environment（E2 已有强规律，作对照因素）与 relation / binding（E1 失败因素）。E3 只支持"条件相关、模型相关的组合难度异质性"表述，不支持"未见组合泛化下降"表述（冻结模型无"见过/没见过"定义，方案 §51）。

6. 遗留缺口

  1. e3_items_cogent.jsonl 缺 negative_color / negative_shape 字段（§4.4），下次 E3 重跑补上；
  2. E2 的配对清单未落盘，逐对比对不可复核；
  3. 方案文档没有"采样平衡"条款，规范层级不一致（当前依据 README Step 3 + 代码 docstring）；
  4. vitb32 attribute 0.399 / vitl14 spar relation 0.456 的显著反向读数机制未解释，建议第二阶段一并分析；
