0. 一页结论

  1. 采样修复有效且严格执行。9 个 run 的 pos_value 配额全部精确等额（如 size 1000/1000、relation 500×4），SPAR position 视角翻转比例全部恰为 0.500，"恒选某词"策略的期望准确率被压到恰 1/k，汇总表可由逐题数据重算（偏差 ≤ 2.2e-16）。
  2. E1 因素重新分类（本次复查的核心结论）：
    • 真辨别：scene（0.75/0.89/0.99）、color（0.68–0.71，9/9 run CI 高于 0.5）、object（0.58–0.64，其中 cube 侧 0.88–0.92、cylinder 侧 0.14–0.38）；
    • 纯词偏好、辨别≈0：size（三模型分侧 1.000/0.000，总体恰 0.500）、clevr/relation（vitb32 恒选含 left 的句、vitl14 恒选含 right 的句）、pug_spar/position（总体 0.489–0.503）；
    • 偏好为主 + 少量辨别：material 在 vitb32（分解≈0.03 辨别+0.78 偏好）、siglip2 上混杂；vitl14 材质不对称仅 0.18，以真辨别为主（0.575）；
    • 免疫因素（正负例词集相同）的干净结果：binding 0.495–0.515（9/9 含 0.5，干净的零辨别）；attribute vitb32 0.399 三种子 CI 均低于 0.5（系统性反向）；pug_spar/relation vitl14 0.456 三种子低于 0.5。
  3. 修复改变了三个旧结论：SPAR position"方向随模型翻转"（63.3%/40.8%/54.2%）→ 全部 ≈0.50，旧数字是词偏好伪影；size"略高于随机 52%"→ 0.500 无辨别；clevr relation"51–52% 略高于随机"→ 基本全部可由词偏好解释。颜色−绑定差距保持（三模型 3-seed 均值 17.8–20.7pp，逐 run 范围 17.2–21.1pp，9/9 CI 高于 0）。
  4. E2/E3 不受采样修改影响：报告《预实验结论深化分析》的 E2/E3 数字与当前磁盘逐位核对一致（抽检：E2 env transition gap 0.669/0.641/0.726 全部 CI>0；E3 vitb32 seed0 +3.965pp [+1.898,+5.968]、vitl14 −0.65pp 含 0、siglip2 +3.58pp [1.586,5.705]），结论沿用。
  5. 阶段判定（详见 outputs/STAGE1_SUMMARY.md）：E1"结构薄弱点"证据在平衡采样后比之前更干净（relation/position/size 从"弱信号"变为"可证明的零辨别"）；E2 只有 environment 满足"规律超过 nuisance"；E3 2/3 模型成立。总体接近方案 §68 的情况 A 但 E2/E3 不完整，建议进入第二阶段的小规模受控编辑验证。

3. E1 再分析

3.1 读数方法

平衡后每个因素的读数规则：

  • 总体 accuracy = 干净辨别指标（恒选某词策略期望恰 0.5，总体超出 0.5 的部分只能来自辨别）；
  • 分侧（pos_value）准确率之差 = 词偏好强度；一侧趋近 1、另一侧趋近 0 即"恒选某词"的直接证据；
  • 二值因素可分解：总体 ≈ 0.5 + 辨别项 ± 偏好/2。例：size 三模型分侧 1.000/0.000 → 偏好≈1、辨别≈0；vitl14 material 分侧 0.666/0.483 → 偏好 0.18、辨别 ≈0.075；
  • 免疫因素（binding、attribute、spar relation：正负例词集相同）总体即干净读数，无词偏好可混入。

读法：

  • size 是纯词偏好的教科书案例：三模型全部"恒选含 small 的描述"，large 侧 ≈0、small 侧 ≈1，总体恰 0.500。旧报告里 size 52.0–52.9% "略高于随机"就是正例偏 small 的抽样偏斜（正例含 small 51.5–52.9%），已被 10-28 审计证明，本次平衡数据以更极端的形式确认。
  • clevr/relation 同样无辨别：vitb32 恒选含 left 的句子（left 侧 .996、right 侧 .005），vitl14 反向恒选含 right（.991/.009），siglip2 弱偏好 left（.823/.173）。方向词偏好把总体抬/压到 0.503–0.513，旧报告"relation 略高于随机"的 1–2pp 完全可由偏好解释。

  • object 是辨别+偏好混合：cube 侧 0.88–0.92（偏好或易辨别），cylinder 侧 0.14–0.38（被避开），sphere 侧居中。总体 0.58–0.64 里有真实成分（负例词与正例词在各侧对称出现，纯偏好会给 0.5），但各词难度严重不均。
  • material 模型间质的不同：vitl14 偏好弱（分侧差 0.18）、总体 0.575，以真辨别为主；vitb32 偏好强（0.78）、总体 0.527 = 少量辨别 + 偏好；siglip2 介于两者（偏好 0.55、总体 0.598）。
  • color 的取值依赖：每个模型都有接近随机的颜色（vitb32 brown .516、vitl14 green .446、siglip2 brown .205）和很高的颜色（cyan .93+），总体 0.68–0.71 是真实但严重不均的辨别。
  • 免疫因素的干净读数：binding 9/9 含 0.5——全局零样本打分未能利用绑定信息，与旧结论一致且现在完全排除词偏好解释；vitb32 attribute 0.399 与 vitl14 spar relation 0.456 显著低于随机，是系统性的反向偏好（模型更偏好"换绑/换主客"的错误描述），值得后续单独分析。
