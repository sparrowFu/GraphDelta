## 2. E1 静态结构诊断

### 2.1 读数方法

- 每因素 target=2000 条 2AFC（image→text，7 模板均值，平局记错），正例一侧取值 pos_value 分层等额抽取；
- **总体 accuracy = 干净辨别指标**（恒选某词期望恰 0.5，总体超出 0.5 的部分只能来自辨别）；
- **分侧准确率之差 = 词偏好强度**；一侧趋近 1、另一侧趋近 0 即"恒选某词"的直接证据；
- 二值因素可分解：`总体 ≈ 0.5 + 辨别项 ± 偏好/2`；
- 免疫因素（binding / attribute / spar relation：正负例词集相同）总体即干净读数。

## 3. E2 单因素表示响应

### 3.1 指标与口径（直接对应 e2_delta_stats.csv 列）

- **transition similarity gap**（z 空间）：同因素同转换跨 context 相似度 − 不同因素跨 context 相似度；CI>0 即"具体转换可复现"；
- **norm gap（raw/z）**：‖Δ_factor‖ − ‖Δ_nuisance‖（nuisance = 同图确定性增强视图之差）；CI>0 即响应超出渲染扰动；
- **ratio** = factor_over_nuisance_ratio，>1 即因素响应大于 nuisance；
- 覆盖量取自 e2_transition_stats.csv 的 n_contexts 分布。

### 3.4 解读

- **environment 是唯一全面成立的因素**：两个数据集、三个模型，transition gap 0.64–0.79 全部 CI>0，且范数差 CI>0、ratio 1.7–2.8。支持"具体环境转换跨 context 高度可复现"。
- **texture 数据集依赖**：Animals 上 vitb32/siglip2 的范数差 CI 为负（响应小于 nuisance），ImageNet 上三模型都为正；tgap 两个数据集都为正但幅度小（0.11–0.35）。
- **size / camera 弱**：tgap CI>0 但幅度 ≤0.15；size 在 Animals 的范数差三模型全负、ratio 0.61–0.96；camera 范数差符号随模型翻转。
- **覆盖量警告**：ImageNet environment 的 57.1% 转换只有 1 个 context——该数据集上"跨 context 可复现"的证据集中在其余 43% 的转换上，结论弱于 Animals。Animals environment 每转换平均 6.67 个 context，证据扎实。
- 结论：支持"具体转换（尤其环境转换）有可复现的表示响应"，不支持"每个因素都有统一、可跨转换泛化的方向规律"。

**第二阶段建议**：以小规模受控编辑（Controlled Edit）验证为主——对 relation / binding 的失败直接检验"视觉 Δ 是否不足"与"打分是否不利用"两个假设；受控编辑设计应同时覆盖 environment（E2 已有强规律，作对照因素）与 relation / binding（E1 失败因素）。E3 只支持"条件相关、模型相关的组合难度异质性"表述，不支持"未见组合泛化下降"表述（冻结模型无"见过/没见过"定义，方案 §51）。
