## 3. E1 再分析

### 3.1 读数方法

平衡后每个因素的读数规则：

- **总体 accuracy = 干净辨别指标**（恒选某词策略期望恰 0.5，总体超出 0.5 的部分只能来自辨别）；
- **分侧（pos_value）准确率之差 = 词偏好强度**；一侧趋近 1、另一侧趋近 0 即"恒选某词"的直接证据；
- 二值因素可分解：`总体 ≈ 0.5 + 辨别项 ± 偏好/2`。例：size 三模型分侧 1.000/0.000 → 偏好≈1、辨别≈0；vitl14 material 分侧 0.666/0.483 → 偏好 0.18、辨别 ≈0.075；
- **免疫因素**（binding、attribute、spar relation：正负例词集相同）总体即干净读数，无词偏好可混入。
