# GraphDelta 下一步工作方案：受控结构编辑与迁移验证

制定日期：2026-11-03。依据：[预实验分析报告（平衡采样）](预实验分析报告_平衡采样_2026-11-03.html)、[完整预实验方案](../../../GraphDelta_完整预实验方案_统一修订版.md)、[研究框架](../../../GraphDelta_研究框架_统一修订版.md)。本文是待执行方案，文中的样本数、周期和验收门槛均为建议，不是新增实验结果。

**建议进入第二阶段的小规模机制验证，以颜色归属交换为主任务，以换色为正控制，随后加入左右关系反转。当前的重点是补齐“结构变化—表示变化—跨场景迁移”这条证据链。**

本轮预实验已经提供研究动机，但还不足以支持扩大方法训练。下一轮先冻结骨干，只允许用于诊断的线性探针及训练集方向估计；完整 GraphDelta、LoRA 和可训练的跨模态投影留待阶段判断之后。

**1. 根据结果，重新安排工作优先级。**

| 报告中的证据 | 对下一步的影响 | 优先级 |
|---|---|---|
| CLEVR 颜色准确率约 68.3%–70.5%，颜色归属约 49.5%–51.5% | 将绑定交换作为主任务，用换色确认评测流程能识别较简单变化 | P0 |
| 大小题几乎恒选“小”，左右题存在相反的描述偏好 | 加入真正需要看图的配对评测、候选对称化和文字参照 | P0 |
| B/32 的 SPAR 纹理归属约 39.9%，L/14 的对象顺序约 45.6% | 优先复查原图、标注、句子和预处理；低于参考线可能有系统性原因 | P0 |
| E2 的环境变化最稳定，但没有测结构编辑 | 环境结果用作既有分析流程的参照；新数据必须直接改变绑定或关系 | P1 |
| E3 两个模型存在 A/B 难度差，L/14 的局部差异会相互抵消 | 保留逐组合分析；当前不把 A/B 差异称作未见组合泛化失败 | P2 |

这轮不优先增加模型数量，不全面重跑 E1–E3，也不同时建设动物纹理编辑。先用 CLIP ViT-L/14 打通流程，再用相同清单在 SigLIP2、ViT-B/32 上检验主要发现。

**2. 先完成题目和运行环境审计，预计 1–2 个工作日。**

- 从服务器导出 SPAR 两类稳定低于 50% 的题目，建议每类分层抽查约 100 题，覆盖正例取值、模板、模型一致错及模型分歧情况。逐张确认正句为真、负句为假，检查动物名称、纹理词、关系视角、主客体顺序及裁剪后的可见性。另抽查 CLEVR 绑定题作为对照。
- 对能构造反向状态的题，使用同一对文本，让两句分别在各自对应图片上成为正例；对普通单图题则平衡具体正确—错误取值搭配，并控制被描述对象的顺序。选项编号随机化，保持跨模型一致。
- 加入固定文字规则、只用训练集拟合的文字参照，以及在同题型、相近背景和对象条件内打乱图片的对照。简单字母序参照只能排除一种规则，不能代表所有文字偏差。
- 核对服务器上的原图、模型、CLEVR generator、Blender 和渲染资产能否使用，先生成并检查少量图片。当前配置使用 Linux 服务器路径，仓库未包含完整渲染环境，现阶段不能把本机执行作为已满足条件。

输出一份逐题审查清单和修订后的评测协议。如果发现系统性真值错误、不可见对象或描述歧义，先修复相关题型并重评该部分。已有按标注计算的低分不能替代这一步核验。没有发现问题也只说明抽查范围内可靠。

**3. 构造最小受控数据，先做约 1,000 个编辑对。**

第一批建议 800 对颜色归属交换，加 200 对目标对象换色；另从相同场景家族生成约 200 对无语义变化的扰动对照。每个编辑对指一组 before/after 图片，逆向相减不增加独立样本数。额外的错误编辑候选另行登记。

| 编辑 | 图像变化 | 必须保持或核验的条件 |
|---|---|---|
| 颜色归属交换，主任务 | 红色立方体、蓝色球 → 蓝色立方体、红色球 | 对象身份和形状、位置、大小、材质、相机、光照、背景不变；颜色集合不变 |
| 目标对象换色，正控制 | 只改变一个指定对象的颜色 | 其余对象及所有非颜色条件不变 |
| 左右关系反转，后续增加 500–1,000 对 | 同一对象 A 从 B 左侧变为右侧 | 对象身份、属性、相机和光照不变；按相机坐标安排位置，核验深度关系和可见性 |
| 无语义变化，对照 | 同图压缩、保持对象完整可见的轻微裁剪；关系任务另加共同平移 | 目标颜色归属或相对关系保持不变，并记录变化区域与位移量 |

先使用两个对象，减少指代歧义及与第三个对象的额外关系变化。绑定任务选取约 8 个明确的颜色—形状有向转换，每个转换覆盖约 100 个独立基础场景；在不同基础场景之间改变材质、大小、布局、相机和光照等未被转换定义固定的条件，在每对图片内部保持这些条件不变，以检验跨场景重复性。具体转换名单在正式编码前固定。

不要把所有“颜色交换”的差向量直接平均。红立方体与蓝球交换、绿圆柱与黄立方体交换，不能预先假定共享一个方向。先检验具体转换，再判断是否存在更一般的规律。

关系任务通过重新放置对象生成，不以整图镜像代替。绑定任务交叉平衡形状与左右位置，检查模型是否只追踪“左边变红”；记录对象可见面积和颜色直方图，检查两种形状的面积差是否让整图颜色比例成为捷径。关系任务用共同平移等对照检查绝对位置和运动量的影响。

每对至少保存：`pair_id`、`base_scene_id`、前后图片路径、前后完整文本、对象 ID、前后场景图、结构化编辑指令、转换类型、划分、渲染随机种子、生成器版本、校验状态。颜色交换会改动多个属性绑定，关系反转也会同步改变逆关系；校验“场景图差异符合预期编辑集合”，不能机械地要求只变化一条边。

检查程序覆盖全部样本；每个转换都抽图检查，第一轮建议人工检查至少 10%，异常样本全部复查。渲染缺失、遮挡过重、关系边界不清或正负描述同时为真的样本剔除，并保存原因。

**4. 先划分，再估计方向，避免把重复场景当成泛化。**

- 第一轮按基础场景家族分为训练 / 验证 / 测试，建议 60% / 20% / 20%，各具体转换在三组中均有覆盖。同一基础场景的所有编辑、逆向记录、模板和扰动版本必须在同一组。
- 训练集仅用于方向估计、文字参照及线性探针；验证集用于选择超参数、修改幅度和确定实验规模；测试集用于锁定方案后的评价。
- 本轮主要检验“已知转换在未见场景上的迁移”。它不同于“未见颜色—形状组合”或“未见编辑转换”的迁移。固定转换均值无法直接处理训练中不存在的转换，后者应单独设计。
- 约 1,000 对是先导规模。800 个绑定对按上述比例划分后，只有约 160 个测试场景，不能默认足够确认 5 个百分点的小提升。先依据训练与验证数据中的配对差异、方法间预测分歧和场景内相关性估计正式测试规模；若已经查看先导测试结果，后续确认实验使用新封存的场景。

不同模型使用同一划分。若改变划分种子，应分别报告；不能将重叠的测试场景合并成独立样本。

**5. 阶段二实验 E4：依次判断“能区分、能读出、能迁移”。**

对每个图片对及对应文本，计算完整的 2×2 相似度矩阵。令 `Sij = sim(image_i, text_j)`，其中 0 为编辑前，1 为编辑后。

| 子实验 | 做法 | 主要输出和解释 |
|---|---|---|
| E4-A：配对结构判断 | 两张图分别在同一对文本中选描述；两句文本也分别在同一对图中选图片 | I2T、T2I，以及前后两张图均选对的 Pair Accuracy；检查是否随图改变选择 |
| E4-B：视觉变化诊断 | 计算 Δv；比较同一具体转换在不同场景中的方向，与其他转换及扰动对照比较 | 同转换一致性、变化长度、方向近零比例和留出场景上的线性探针表现 |
| E4-C：跨模态变化诊断 | 计算对应 Δt；比较正确编辑配对、方向或对象角色错误的编辑配对，以及匹配置换 | 图文差向量的一致性与编辑辨识；同时报告长度，避免近零差向量归一化放大噪声 |
| E4-D：跨场景方向迁移 | 仅用训练集估计具体转换方向，在留出场景预测编辑后的表示 | 检验方向是否能迁移，而非仅在用于估计方向的图片上成立 |

E4-A 保留现有七模板逐模板评分再平均的口径；Pair Accuracy 也须先在同一个模板内判断两张图是否均对，再跨模板平均。另报告平局率和各模板结果。恒选同一句的策略在前后两图等权时只能取得约 50% 的单图准确率，Pair Accuracy 为 0（平局规则另外注明）。

可报告配对分数 `C = S00 + S11 − S01 − S10`。在相同归一化表示及点积打分下，它恰好等于 `Δv · Δt`。因此，配对分数为正与图文 delta 点积为正存在代数关系，不能将二者当成两份独立的机制证据。Pair Accuracy 的参考分布也不能一概按 25% 处理，建议采用场景内匹配置换建立经验零分布。

线性探针保持骨干冻结，按场景划分训练和测试；分别读出静态关系/归属，以及变化类型或具体方向。加入像素差、颜色直方图变化等低层参照，检查探针是否只利用变化面积或颜色比例。探针可读出信息，只支持“有信息可被读取”，不自动支持“原图文打分能利用它”或“沿方向修改就有效”。

**6. 简单方向迁移必须有明确输入和强对照。**

先做一个明确的条件任务：给定编辑前图片和预先规定的编辑指令，预测编辑后的视觉表示。对每个已知具体转换 r，使用训练集估计平均方向 `d_r` 并固定符号，在验证集选择非负幅度 `α ≥ 0`，测试时计算：

`预测表示 = normalize(编辑前表示 + α × d_r)`

真实 after 表示仅在评分时使用；不能用当前测试图片对的真实差向量当作预测方向，也不能根据哪个候选是正确答案来决定方向或符号。非负幅度约束适用于所有方向对照，否则正确方向和反向方向可通过负幅度搜索变成同一个方法。所有方法使用相同的可用输入；若输入使用人工真值场景图，应明确标为依赖该额外信息的机制实验。

比较以下对照，方向范数和幅度搜索预算保持可比：

| 对照 | 排除什么解释 |
|---|---|
| 不修改，α=0 | 原始表示本来就接近目标 |
| 正确转换的训练集平均方向 | 待验证的跨场景迁移 |
| 同类操作但颜色/对象角色错误的方向 | 只是识别了粗略的编辑类型 |
| 随机方向、反向方向 | 任意扰动或普遍改变分数即可获益 |
| 在同一具体转换内打乱 before/after 跨场景配对后估计的方向 | 场景配对信息是否必要；该均值有可能与正确配对完全相同，不能预设它是必然失效的负对照 |
| 由相应文本差构造的等幅方向 | 直接推高目标文字分数的机械效应 |

需要特别注意：如果每个转换使用完全相同的一组 before 与 after 样本，打乱配对后再求平均，均值仍是 `mean(after) − mean(before)`，与正确配对均值完全一样。因此，简单平均方向实验不能凭“打乱配对”证明学习了逐场景结构对应；逐场景对齐和条件预测要另行检验。

迁移实验的唯一主终点指定为“在预先固定候选池中检索真实 after 图片的 top1 准确率”。候选包含原图、正确编辑图和同一基础场景的错误编辑图；另加入同指令但不同场景的候选，检查是否保留原场景信息。候选池大小、构造规则、平局规则和清单在测试前固定，所有方法使用同一候选池。预测表示与真实 after 表示的距离、文本排序作为辅助指标，并检查身份、形状及未编辑属性的判断是否受损。

该任务验证“已知指令下的表示变换”。即使成功，也不能直接称为普通单图 2AFC 已被修复。若后续主张静态匹配改善，须提供仅依赖单图和候选文本、无需正确标签或真实 after 图片的推理流程，并单独评价。

**7. 使用预先约定的阶段判断，决定是否扩大。**

所有差值在同一批测试场景上配对计算，按基础场景家族聚类 bootstrap。涉及两端场景的方向比较需处理两端依赖。报告独立场景数、转换数、逐转换效应和 95% 区间；模板、逆向记录、重复抽样种子不充当额外独立样本。保留原始与归一化空间，但预先指定主指标，避免事后挑选最有利口径。

建议正式确认实验将“固定候选池的 after 图片检索 top1 准确率，比验证阶段预先选定的最强可比基线提升至少 5 个百分点、配对 95% 区间下界高于 0”作为实用目标；同时检查各强对照，身份/颜色保持任务下降不超过预设容忍值，例如 2 个百分点。5 和 2 均是建议的项目门槛，须在看正式测试结果前固定，不是通用统计定律。距离等连续指标另外报告效应量及区间，I2T 和 Pair Accuracy 不替代迁移实验的主终点。

| 观察结果 | 后续动作 |
|---|---|
| 正控制失败，或原图/文本审计发现系统性问题 | 先修复数据、预处理或评分，不开展完整训练 |
| 绑定变化在留出场景可辨识、跨模态对应清楚，且方向迁移优于强对照、保留未编辑语义 | 扩到关系编辑；在另一模型确认后，制定完整 GraphDelta 训练方案 |
| 固定方向失败，但线性探针或局部特征能读出关系/绑定 | 检查对象区域、上下文依赖和匹配头；不能据此否定所有结构变化建模 |
| 视觉变化可辨识，但图文对应弱 | 聚焦文字表达与跨模态匹配，暂不声称冻结模型已有可用的共享方向 |
| 只有文本 margin 改善，随机/文本差方向也同样有效，或真实 after 检索不改善 | 不归因于可迁移的结构变化；先查分数偏移与语义保持 |
| 只在训练场景有效 | 排查场景记忆、重复图片及划分泄漏 |
| 区间宽、覆盖有意义的正负效应 | 判为证据不足；依预定规则增加独立场景，不能写成已证明无效 |

进入方法阶段时，至少保留同训练数据、相近参数量和训练预算的对照：普通微调、hard-negative 训练、仅状态结构对齐、固定 delta、去掉图编辑监督的同容量方法，再与上下文相关 GraphDelta 比较。这样才有条件区分收益来自额外训练、结构监督还是变化建模。

若之后研究未见组合，则专门规定适配模块只在 CoGenT A 或自建组合训练集上训练，在留出 A 和 B 上测试，按颜色、形状、题型和具体负例分层报告。预训练骨干可能已经见过相关概念；“未见”只针对本研究的适配训练划分，不能扩展成预训练历史结论。

**8. 实施顺序、交付物和代码范围。**

下面按渲染环境、模型和原图可访问的前提，建议安排约 2–3 周先导工作；渲染环境安装和正式确认实验扩样另计。

| 时间建议 | 工作 | 可审查交付物 |
|---|---|---|
| 第 1–2 天 | SPAR 原图审计、候选规则复核、服务器渲染试通 | 审查表、冻结版评测协议、少量带标注图 |
| 第 3–5 天 | 先生成每类数十对，验证后扩到约 1,000 对；固定场景划分 | 配对清单、前后场景图、校验报告、人工抽查图集 |
| 第 2 周 | ViT-L/14 跑 E4-A/B/C，完成线性探针及精度敏感性检查 | 配对矩阵、逐题记录、逐转换统计、诊断图 |
| 第 3 周 | E4-D 迁移与强对照，视结果加入左右关系和跨模型复核 | 留出场景效果表、失败案例、继续/调整决定 |

现有代码可以复用：编码器 `src/models/`，图文特征 `src/features/`，文本构造 `src/data/captions.py`，多模板评分 `src/experiments/common.py`，配对与相似度指标 `src/metrics/`，聚类统计 `src/metrics/bootstrap.py`。以下是建议新增模块，尚未实现：

- 受控场景生成、场景图编辑和一致性校验；
- 持久化的编辑对清单及按场景家族划分；
- E4 完整配对评测、探针和跨场景方向迁移脚本；
- 每次运行保存清单哈希、模型与预处理指纹、生成器/环境版本、实际代码快照和超参数。

现有图像和文本缓存会保存为 float16。新实验建议使用独立命名空间的 float32 缓存，并在一小批样本上比较存储精度，特别检查很小的绑定/关系差向量；将旧缓存读回 float32 不能恢复量化精度。现有正式报告、旧结果和缓存保留，以便比较。

本方案的首个执行项是取得可核验原图并试通受控渲染；首个研究交付是“绑定交换在新场景上是否存在可辨识、跨模态对应且可迁移的变化规律”的阶段判断。
