**2. 先完成题目和运行环境审计，预计 1–2 个工作日。**

- 从服务器导出 SPAR 两类稳定低于 50% 的题目，建议每类分层抽查约 100 题，覆盖正例取值、模板、模型一致错及模型分歧情况。逐张确认正句为真、负句为假，检查动物名称、纹理词、关系视角、主客体顺序及裁剪后的可见性。另抽查 CLEVR 绑定题作为对照。
- 对能构造反向状态的题，使用同一对文本，让两句分别在各自对应图片上成为正例；对普通单图题则平衡具体正确—错误取值搭配，并控制被描述对象的顺序。选项编号随机化，保持跨模型一致。
- 加入固定文字规则、只用训练集拟合的文字参照，以及在同题型、相近背景和对象条件内打乱图片的对照。简单字母序参照只能排除一种规则，不能代表所有文字偏差。
- 核对服务器上的原图、模型、CLEVR generator、Blender 和渲染资产能否使用，先生成并检查少量图片。当前配置使用 Linux 服务器路径，仓库未包含完整渲染环境，现阶段不能把本机执行作为已满足条件。

输出一份逐题审查清单和修订后的评测协议。如果发现系统性真值错误、不可见对象或描述歧义，先修复相关题型并重评该部分。已有按标注计算的低分不能替代这一步核验。没有发现问题也只说明抽查范围内可靠；审计对象按低分题型选取，发现不了高分题型的真值错误，相关结论同样限定在抽查范围。若渲染环境在审计期内无法跑通，记为阻塞项：先修复或确定替代生成方案，未解决前不生成正式数据，时间影响按第 8 节的裁剪顺序处理。

**3. 构造最小受控数据，先做约 1,000 个编辑对。**

第一批建议 800 对颜色归属交换，加 200 对目标对象换色；另从相同场景家族生成约 200 对无语义变化的扰动对照。每个编辑对指一组 before/after 图片，逆向相减不增加独立样本数。额外的错误编辑候选另行登记。

第二阶段默认再完成 500–1,000 对左右关系反转诊断，即总计约 1,500–2,000 个语义编辑对。两项任务均纳入首版主张。若受渲染可用性或资源上限限制而需缩小范围，应在查看新模型效果前、正式批量生成时决定并记录；依据仅为技术质量与预算，不以效果是否有利筛选任务。省去关系时同步将研究主张与主指标改为仅绑定。关系任务同样先固定具体转换和独立场景配额，再开始生成。

| 编辑 | 图像变化 | 必须保持或核验的条件 |
|---|---|---|
| 颜色归属交换，主任务 | 红色立方体、蓝色球 → 蓝色立方体、红色球 | 对象身份和形状、位置、大小、材质、相机、光照、背景不变；颜色集合不变 |
| 目标对象换色，正控制 | 只改变一个指定对象的颜色 | 其余对象及所有非颜色条件不变 |
| 左右关系反转，本阶段增加 500–1,000 对 | 仅移动 A，使其从 B 左侧变到右侧，B 保持原位 | 对象身份、属性、相机和光照不变；按相机坐标安排位置，A、B 间距与相对深度在编辑前后保持不变，使左右关系反转成为唯一系统性位置变化；核验可见性 |
| 无语义变化，对照 | 同图压缩、保持对象完整可见的轻微裁剪；关系任务另加共同平移 | 目标颜色归属或相对关系保持不变，并记录变化区域与位移量 |

先使用两个对象，减少指代歧义及与第三个对象的额外关系变化。绑定任务选取约 8 个明确的颜色—形状有向转换，每个转换覆盖约 100 个独立基础场景，8 个转换的基础场景集合互不相交，800 对即对应 800 个独立基础场景；若复用场景，须同步修正第 4 节的独立场景数和功效估计。在不同基础场景之间改变材质、大小、布局、相机和光照等未被转换定义固定的条件，在每对图片内部保持这些条件不变，以检验跨场景重复性。具体转换名单在正式编码前固定。原方案第二阶段清单中的 EditCLEVR 第一版不引入：本阶段需要场景图级校验以及关系、绑定两类编辑，统一自建渲染可以保证同一套校验口径；单对象属性编辑已由换色正控制覆盖。后续若引入外部编辑数据，须先单独审计其标注。

默认 8 个绑定转换为：cube–sphere 使用 `(red,blue)`、`(red,green)`、`(blue,yellow)`、`(green,yellow)`；cylinder–sphere 使用 `(gray,brown)`、`(gray,purple)`、`(brown,cyan)`、`(purple,cyan)`。编辑前目标形状取首色、sphere 取次色，编辑后交换；逆向复用同一 pair ID。关系诊断从第 9.3 节的 10 个合法训练类型对中等额取独立场景，按固定类型顺序统一 left→right 符号，不改变语义标签或增加逆向样本计数。

不要把所有“颜色交换”的差向量直接平均。红立方体与蓝球交换、绿圆柱与黄立方体交换，不能预先假定共享一个方向。先检验具体转换，再判断是否存在更一般的规律。

关系任务通过重新放置对象生成，不以整图镜像代替。绑定任务交叉平衡形状与左右位置，检查模型是否只追踪“左边变红”；记录对象可见面积和颜色直方图，检查两种形状的面积差是否让整图颜色比例成为捷径。关系任务用共同平移等对照检查绝对位置和运动量的影响。

每对至少保存：`pair_id`、`base_scene_id`、前后图片路径、前后完整文本、对象 ID、前后场景图、结构化编辑指令、转换类型、划分、渲染随机种子、生成器及资源版本、校验状态。颜色交换会改动多个属性绑定，关系反转也会同步改变逆关系；校验“场景图差异符合预期编辑集合”，不能机械地要求只变化一条边。节点 ID 和排序不得固定标记正确状态；图节点顺序、文本对象顺序的扰动对所有方法一致。

检查程序覆盖全部样本；按转换分层随机抽取至少 10% 的完整图片对及两句文本人工核验，检查者尽量不看模型分数，核验使用预先固定的逐项清单（正句为真、负句为假、对象可见、指代无歧义），登记分歧、剔除率及原因，异常样本全部复查。单人核验时另抽约 5% 间隔数日后复核一遍，报告两次判定的不一致率。渲染缺失、遮挡过重、关系边界不清或正负描述同时为真的样本剔除。加入少量完全相同场景的重复渲染，测量渲染随机性；关系编辑另查投影面积、深度、遮挡和阴影变化。抽查未发现错误不能表述为全部数据无错误。

**4. 先划分，再估计方向，避免把重复场景当成泛化。**

- 第一轮按基础场景家族分为训练 / 验证 / 留出机制集，建议 60% / 20% / 20%，各具体转换在三组中均有覆盖。同一基础场景的所有编辑、逆向记录、模板和扰动版本必须在同一组。
- 训练集用于方向估计、文字参照及线性探针；验证集用于选择超参数、修改幅度和估计实验规模；留出机制集用于锁定诊断程序后的评价，不用于自动调参或选 checkpoint。该集及同家族禁止进入主实验训练和第 0 步训练，单独登记清单与哈希。
- 本轮主要检验“已知转换在未见场景上的迁移”。它不同于“未见颜色—形状组合”或“未见编辑转换”的迁移。固定转换均值无法直接处理训练中不存在的转换，后者应单独设计。
- 约 1,000 对是先导规模。800 个绑定对按上述比例划分后，只有约 160 个测试场景，不能默认足够确认 5 个百分点的小提升。本阶段报告效应量和不确定性，并依据训练与验证数据估计主实验的测试规模；不为追求固定方向显著获益而反复扩样。主实验使用另行封存的新场景。

不同模型使用同一划分。若改变划分种子，应分别报告；不能将重叠场景合并成独立样本。第二阶段正式数据优先遵守第 9.3 节的训练允许组合，以便开发数据后续复用；任何进入主训练的数据仍须重新经过全入口组合审计。留出机制集虽保持训练未见，但其结果已用于诊断，只作为后续前后机制分析的辅助证据；主实验确认性结论使用新封存测试数据。

**5. 阶段二实验 E4：依次判断“能区分、能读出、能迁移”。**

对每个图片对及对应文本，计算完整的 2×2 相似度矩阵。令 `Sij = sim(image_i, text_j)`，其中 0 为编辑前，1 为编辑后。

| 子实验 | 做法 | 主要输出和解释 |
|---|---|---|
| E4-A：配对结构判断 | 两张图分别在同一对文本中选描述；两句文本也分别在同一对图中选图片 | I2T、T2I，以及前后两张图均选对的 Pair Accuracy；检查是否随图改变选择 |
| E4-B：视觉变化诊断 | 计算 Δv；比较同一具体转换在不同场景中的方向，与其他转换及扰动对照比较 | 同转换一致性、变化长度、方向近零比例和留出场景上的线性探针表现 |
| E4-C：转换级跨模态诊断 | 计算对应 Δt；比较正确转换与同词集但方向/角色错误的转换；按冻结规则置换转换对应 | 转换级一致性及编辑辨识；不据固定短文本声称逐场景跨模态对应 |
| E4-D：跨场景方向迁移 | 仅用训练集估计具体转换方向，在留出场景预测编辑后的表示 | 检验方向是否能迁移，而非仅在用于估计方向的图片上成立 |

E4-A 保留现有七模板逐模板评分再平均的口径；Pair Accuracy 也须先在同一个模板内判断两张图是否均对，再跨模板平均。平局记错，与第 9.4 节主实验口径一致；另报告平局率和各模板结果。恒选同一句的策略在前后两图等权时只能取得约 50% 的单图准确率，Pair Accuracy 为 0（平局规则另外注明）。

可报告配对分数 `C = S00 + S11 − S01 − S10`。在相同归一化表示及点积打分下，它恰好等于 `Δv · Δt`。因此，配对分数为正与图文 delta 点积为正存在代数关系，不能将二者当成两份独立的机制证据。Pair Accuracy 的参考分布也不能一概按 25% 处理，建议采用场景内匹配置换建立经验零分布。

线性探针保持骨干冻结，按场景划分训练和评价；分别读出静态关系/归属，以及变化类型或具体方向。全部标准化、中心化及超参数只用训练/验证数据确定，不使用待预测的测试转换标签处理特征。加入像素差、颜色直方图及单端点表示参照，并平衡源状态与编辑类型，检查分类是否只依赖变化面积、颜色比例或某一端的静态属性。探针成功只支持信息可被读取；失败也不能证明所有信息均已丢失。

E4-B 保留具体转换的共享均值作为待检验信号。仅用训练集估计 `d_r = mean(Δv_train,r)`，在留出场景报告与 `d_r` 的方向相似度、预测误差和近零 delta 比例，配合布局、位移、面积及重复渲染对照解释。每转换仅约 60 个训练场景用于估计数百维方向，方向相似度数值会系统性偏小；判断以与随机方向、错误方向的相对比较为准，不设绝对 cosine 门槛。不得要求“去转换均值后残差仍两两同向”：完美共享方向在中心化后全为零，且中心化残差满足 `Σ_(i<j) r_i·r_j = −½Σ_i||r_i||²`，整体内积非正。上下文相关残差只作描述或主实验的条件预测目标，不用残差同向性作通过条件。

E4-C 第一版使用只含颜色和形状的绑定短描述。同一具体转换、同一模板的 Δt 在不同场景中相同，因此同转换内打乱文字与场景配对是无效对照；主分析限定为转换级，并报告独立转换数。转换级统计的独立单位只有绑定的 8 个转换和关系的 10 个类型对，结论措辞受此样本量约束，不使用“转换间普遍一致”一类超出数据的表述。若以后增加材质、位置等上下文文本，应单列任务和核验规则，再设计逐场景错配，不能将两套协议合并解释。

**6. 简单方向迁移必须有明确输入和强对照。**

先做一个明确的条件任务：给定编辑前图片和预先规定的编辑指令，预测编辑后的视觉表示。对每个已知具体转换 r，使用训练集估计平均方向 `d_r` 并固定符号，在验证集选择非负幅度 `α ≥ 0`，测试时计算：

`预测表示 = normalize(编辑前表示 + α × d_r)`

真实 after 表示仅在评分时使用；不能用当前测试图片对的真实差向量当作预测方向，也不能根据哪个候选是正确答案来决定方向或符号。非负幅度约束适用于所有方向对照，否则正确方向和反向方向可通过负幅度搜索变成同一个方法。所有方法使用相同的可用输入；若输入使用人工真值场景图，应明确标为依赖该额外信息的机制实验。

每个任务使用一个在验证集选择的全局非负 α，避免在每转换少量验证场景上分别挑幅度；所有方法使用相同搜索表。非零对照方向缩放到相应训练方向的长度，近零方向单列；随机方向的种子和数量预先固定，汇总全部随机方向而不挑选测试最佳者。比较如下：

| 对照 | 排除什么解释 |
|---|---|
| 不修改，α=0 | 原始表示本来就接近目标 |
| 正确转换的训练集平均方向 | 待验证的跨场景迁移 |
| 同类操作但颜色/对象角色错误的方向 | 只是识别了粗略的编辑类型 |
| 随机方向、反向方向 | 任意扰动或普遍改变分数即可获益 |
| 同转换内打乱配对的均值方向（代数自检） | 完整保留两端样本时应与原均值一致；不作为性能负对照或逐场景学习的证据 |
| 由相应文本差构造的等幅方向 | 直接推高目标文字分数的机械效应 |

需要特别注意：如果每个转换使用完全相同的一组 before 与 after 样本，打乱配对后再求平均，均值仍是 `mean(after) − mean(before)`，与正确配对均值完全一样。因此，简单平均方向实验不能凭“打乱配对”证明学习了逐场景结构对应；逐场景对齐和条件预测要另行检验。

迁移实验的唯一主终点指定为“在预先固定候选池中检索真实 after 图片的 top1 准确率”。候选包含原图、正确编辑图和同一基础场景的错误编辑图；另加入同指令但不同场景的候选，检查是否保留原场景信息。候选池大小、构造规则、平局规则和清单在测试前固定，所有方法使用同一候选池。预测表示与真实 after 表示的距离、文本排序作为辅助指标，并检查身份、形状及未编辑属性的判断是否受损。

包含原图时，不修改的查询与原图候选完全相同，α=0 的 after 检索常会机械地为零。该结果只作流程参照，不能据“优于不修改”宣称迁移有效；主要比较正确方向与等幅的错误、随机、文本差方向，并结合目标表示距离解释。候选若改变对象集合或编辑难度，按候选类型单独报告。

该任务验证“已知指令下的表示变换”。即使成功，也不能直接称为普通单图 2AFC 已被修复。若后续主张静态匹配改善，须提供仅依赖单图和候选文本、无需正确标签或真实 after 图片的推理流程，并单独评价。

**7. 明确预实验结束条件，不把方法有效性提前当作门槛。**

所有差值在同一批测试场景上配对计算，按基础场景家族聚类 bootstrap。涉及两端场景的方向比较需处理两端依赖。报告独立场景数、转换数、逐转换效应和 95% 区间；模板、逆向记录、重复抽样种子不充当额外独立样本。保留原始与归一化空间，但预先指定主指标，避免事后挑选最有利口径。逐转换、逐模板的结果按探索性描述报告；预实验结论只依据预先指定的主指标及其对照，不从多个转换中事后挑选显著者下结论。

撤销上一版将固定方向提升 5 个百分点设为潜在准入门槛的安排。固定方向迁移、原始图文 delta 对齐均是诊断结果，可以成功、失败或只在部分条件下成立。GraphDelta 的主实验正要检验训练是否能改善上下文依赖和跨模态几何；预实验无需先证明训练后的收益。

正式 E4 运行前冻结统计量、主/辅助指标、可交换性假设、置换单位与分层、置换次数、显著性水平及多项判断规则。默认每项计划使用 1,000 次置换、显著性水平 0.05；不足以稳定估计时报告不确定性，不事后换统计量挑显著结果。经验零分布、数值分位数和 p 值在模型输出产生后按冻结程序计算，不能要求模型运行前得到这些数值。随机方向和跨转换对照检验不同问题，不替代标签置换。

质量验收与机制判断分开：图像标注、负例真假、划分、有限值、可重复评分及正控制的实际语义变化是必要质量检查；正控制的模型性能也报告效应与区间，信号弱时先查流程及样本精度，不能仅因未显著就断言数据无效。结构可辨识性、转换级跨模态对应和方向迁移分别记为“有支持证据”或“证据不足”，不要求后三项全部阳性。主要判断使用各自预先指定的指标与对照；多个确认性检验采用预先固定的 Holm 校正，逐转换/模板结果作探索性描述。跨模态对齐和固定方向获益不作为结束预实验的硬门槛。

结束预实验所需的最低交付是：

1. 主张覆盖的任务有可靠受控图像、完整编辑标注和审核记录，换色正控制的语义及评分流程通过质量检查；
2. 在留出场景上报告结构状态/编辑的可辨识性、跨模态对应及固定方向迁移，能够说明哪些观察支持当前表示路线、哪些构成其局限；
3. 明确观察是否受文字规律、绝对位置、变化面积等捷径影响；证据不足与无效区分报告；
4. 完成第 9 项的主实验协议，确定训练模块、数据划分、推理接口、主指标、基线和预算。

有可信的结构区分信号或可读出的结构信息，即使固定方向不成功、原始跨模态对齐偏弱，也可据此进入上下文相关与对齐训练。固定方向失败本身不能证明上下文建模有效，噪声或表示较弱也可能导致失败，其必要性仍由主实验的同容量消融判断。若全局表示缺乏信号而局部表示有信号，先明确采用局部表示的主实验版本；若所有候选表示均缺乏可信信号，则应调整骨干/可训练范围或缩小研究主张，不能把这类结果写成已支持原路线。

| 观察结果 | 后续动作 |
|---|---|
| 正控制图像/标注不一致，或评分与划分有系统性问题 | 先修复数据、预处理或评分，不开展完整训练 |
| 结构变化可辨识，跨模态对应与固定方向迁移均较好 | 结束预实验，进入主实验检验显式训练是否带来额外收益 |
| 固定方向失败，但线性探针或局部特征能读出关系/绑定 | 结束诊断并据此固定上下文相关或局部表示路线；主实验比较固定方向与条件化方法 |
| 视觉变化可辨识，但图文对应弱 | 将对齐不足作为主实验动机，检验对齐训练；不声称原始模型已有共享方向 |
| 只有文本 margin 改善，随机/文本差方向也同样有效，或真实 after 检索不改善 | 不归因于可迁移的结构变化；先查分数偏移与语义保持 |
| 只在训练场景有效 | 排查场景记忆、重复图片及划分泄漏 |
| 固定方向效果区间宽，但数据与其他诊断可靠 | 将迁移结果记为证据不足，按效应范围设计主实验规模；不为固定方向结果无限延长预实验 |

主实验使用相同训练数据、相近可训练参数量与训练预算，比较普通适配训练、hard-negative 训练、仅状态结构对齐、无上下文的编辑变换，以及完整 GraphDelta。预实验的固定方向搬运只用于给定编辑指令的任务；若作为普通图文匹配基线，必须另行定义同样不依赖测试真值的推理接口，不能直接将两类任务的准确率相比较。

主实验首版使用第 9.3 节自建的组合划分；CoGenT A/B 作为可选附加诊断，不能直接替代绑定交换的合法编辑划分。预训练骨干可能已经见过相关概念；“未见”只针对本研究的适配训练范围，不扩展为预训练历史结论。

**9.1 固定研究问题与主次任务。**

主问题建议表述为：在相同数据、可训练容量和训练预算下，图编辑指导的上下文相关变化学习，能否提高模型对未见属性组合与关系结构的图文匹配能力，同时保持已有识别能力？

第一版以绑定和左右关系为核心，换色及身份/形状识别用于控制与保持性评价。物体替换、大小、真实图像、多步编辑作为主实验的后续扩展，不再扩为额外预实验阶段。主实验的预设假设是“变化监督是否优于仅状态监督”“上下文相关是否优于固定变换”“收益是否存在于组合留出集”，允许结果否定这些假设。

骨干范围第一版固定：CLIP ViT-L/14 完成完整基线与消融，SigLIP2 复核主结论。第二骨干的最小对照固定为冻结原模型、hard-negative 适配、2×2 配对目标、不依赖上下文的变换和完整 GraphDelta；若声称图结构贡献跨骨干成立，再补同编辑信息的平坦编码。扩展范围在正式训练前按预算固定，不能看效果后选择性删去不利基线。ViT-B/32 为可选扩展。

许可事实与项目范围分开：PUG 官方采用 CC-BY-NC 并限制训练生成式模型，官网同时明确包括判别式训练用途，因此不存在由这些条款推出“一律只能评测”的依据。[官方 FAQ](https://pug.metademolab.com/)、[官方许可证](https://github.com/facebookresearch/PUG/blob/main/LICENSE.md)。本项目第一版主动将 PUG 限于评测，不进入训练或选模；SPAR 纹理归属仅作动机或附加评测，不声称已训练纹理编辑。是否加入附加评测在主实验协议冻结时确定。

真实图像、额外物体数量和多步编辑为后续主实验扩展。第一版仅支持规定的两对象合成域、模板及组合划分；跨骨干复现不能等同跨真实域泛化。若主张扩大，另做预先定义的域、模板或组合划分验证。

**9.2 固定训练与推理接口，确保变化监督能改变实际匹配。**

首版可采用冻结骨干加轻量匹配适配层，明确实际打分为：

`z_v = normalize(g_v(f_v(image)))`

`z_t = normalize(g_t(f_t(text)))`

`score(image, text) = z_v · z_t`

训练时由场景图提供对象、属性、关系及编辑监督；辅助头 `F(context, edit)` 预测表示变化，结合状态匹配、变化预测、跨模态变化对齐及必要的编辑辨识目标训练。模块结构、更新图像侧/文本侧还是两侧、损失权重、归一化空间与 stop-gradient 位置在主实验前固定。

首版训练目标的接口固定如下，具体权重、margin、温度和网络宽度只在开发集选择，随后写入版本化配置：

- `L_state`：带语义真值掩码的多正例图文对比损失，包含前后两端；其他同样正确的图片/文本不得作为负例。
- `L_pair = mean([m−(S00−S01)]_+ + [m−(S11−S10)]_+)`：使用完整 2×2 图文配对的排序目标，m 为正 margin。
- `L_pred = mean_(模态,方向) ||F_m(sg(z_before),q_edit) − (z_after−z_before)||²`：sg 只作用于传入 F 的源表示副本，目标差中的两个实际匹配表示均保留梯度，F 与编辑编码器正常训练；逆向编辑同样训练，但不增加独立场景数。
- `L_align = mean ||(z_v,after−z_v,before) − (z_t,after−z_t,before)||²`：两个实际匹配表示分支均接收梯度。
- `L_anchor = mean ||z−sg(h)||²`：h 为同维度冻结原表示，限制适配层漂移。首版适配层保持原维度并以近似 identity 初始化。
- 完整模型为 `L_state + λ_pair L_pair + λ_pred L_pred + λ_align L_align + λ_anchor L_anchor`，各项权重为正；消融仅将指定项置零，其他设置和调参预算相同。首版不增加独立编辑分类损失；若以后加入，分类器只读取观测 delta，不能一边输入真实编辑标签一边预测同一标签。

状态、配对和锚定目标用于抵抗常量表示/零 delta 退化，但不能仅凭损失下降认为已避免坍塌。训练中监测表示方差、有效秩、delta 范数、状态匹配和保持指标。与零变化预测器及只读编辑指令的预测器比较；所有 stop-gradient 位置与损失逐项开关均有梯度检查。负例通过完整场景真值检查，多正例与重复短文本的处理规则对所有方法一致。

L_pred 的目标表示随适配层共同学习，因此它是塑造表示几何的约束，不是对固定观测 delta 的纯回归；训练损失下降不能单独证明结构预测更准确。完整、无上下文和平坦编辑版本都使用上述同一 Δ 分支梯度路径，避免无上下文版本因目标被截断而只训练辅助头。匹配与机制效果仍由独立留出评价判断。

变化对齐的归因须利用已知等式：点积 delta 目标等于 `C`；平方差等于 `||Δv||²+||Δt||²−2C`。第 9.5 节加入相同 2×2 样本的配对目标，以及必要的 C/范数分解控制，避免把等价状态损失的重加权当成独立变化机制。数学等价的实现只作一致性检查，不重复计为不同创新证据。

至少一条变化监督的梯度必须进入最终用于匹配的 `g_v/g_t` 或所选择更新的骨干。若只训练 F，而匹配表示始终冻结，测试时再删除 F，普通图文匹配分数不会改变，不能据此检验 GraphDelta 的匹配收益。

普通匹配测试只输入图片和候选文本，场景图、真实编辑、另一状态图片及正确候选标签均不作为额外推理输入。给定编辑指令的 after 检索作为独立机制任务，单独报告。若另做依赖图的推理版本，需单列结果，不与无图版本混为一项。

现有 `src/models/clip_encoder.py` 使用 no_grad 并返回 NumPy，适合冻结特征抽取。使用冻结缓存训练 PyTorch 适配层可复用这些特征；若更新骨干或使用 LoRA，则必须新增可微前向路径，不能直接复用当前评估接口训练骨干。可训练范围按研究框架分为三档：冻结骨干加适配层、仅投影层、部分微调（LoRA）。第一版固定为冻结骨干加适配层；后两档是否纳入在协议中预先写明并由预算决定，不作为事后追加项。

冻结全局特征的路线有信息上限：相同输入特征不能被确定性适配层重新区分。若诊断提示局部信息可读而全局信息弱，应在正式训练前固定局部输入或骨干更新的独立版本；其额外参数与成本单列。全局适配层失败不能被扩大解释为所有 GraphDelta 路线均无效。

**9.3 固定真正的组合留出及测试封存。**

主实验具有训练集、IID 验证/测试集，以及组合 OOD 验证/测试集，按基础场景家族完全隔离。下面给出首版默认规则；正式批量生成前实现枚举校验并保存配置、清单与哈希。若因资源或技术问题调整，须在相关模型结果出现前冻结新规则，不能生成后再挑有利划分。

绑定面板将八色固定为 `G0={red,blue}`、`G1={green,yellow}`、`G2={gray,brown}`、`G3={purple,cyan}`：

| 目标形状 | 训练允许颜色 | OOD 验证颜色 | OOD 测试颜色 |
|---|---|---|---|
| cube | G0∪G1 | G2 | G3 |
| cylinder | G2∪G3 | G0 | G1 |
| sphere | 八色均可见 | 作为锚点 | 作为锚点 |

绑定仅做 cube–sphere 和 cylinder–sphere。每次交换的两种颜色必须都来自目标形状在相应划分的允许颜色集合：训练交换可从该形状四个训练色中任取不同两色，OOD 验证/测试分别使用各自的两色。这样每个 OOD 编辑的前后状态都含有未见的目标形状配色，sphere 提供已见锚点，所有原子颜色/形状在训练出现。首版不做 cube–cylinder 绑定交换，因为其训练色集不相交。第二阶段的 8 个具体绑定转换从合法训练转换中预先选定。

按颜色—形状交换的无向边计数，默认共有 12 个合法训练转换、2 个 OOD 验证转换、2 个 OOD 测试转换；材质、布局和渲染条件在绑定任务中作为 context，不据此增加语义转换数。

该规则体现端点合法性要求：`c1-s1+c2-s2 ↔ c2-s1+c1-s2` 若两端属于训练，四个配色组合均须训练允许。正式清单分别登记 train→train、seen→unseen、unseen→unseen；绑定 OOD 主指标只使用前后状态均包含保留目标配色的最后一类，混合端点单列。

关系面板将对象类型定义为 `(shape,material)`，共六类，只使用不同形状的无序类型对，共 12 类。默认保留：

- OOD 验证类型对：`{cube_metal,cylinder_metal}`；
- OOD 测试类型对：`{cube_rubber,cylinder_metal}`；
- 其余 10 类用于训练及 IID 验证/测试，场景家族分别生成。

每个无序类型对连同左右两种方向、主客体交换和逆关系全部整体划分：`L(a,b)≡R(b,a)`、`R(a,b)≡L(b,a)`。关系反转的两端因此属于同组。六个对象类型及 left/right 在其他训练类型对中均出现。关系面板全部使用上表的训练允许配色，避免同时引入颜色—形状 OOD；其结论准确表述为“未见对象类型对上的左右关系迁移”。

以上两套排除规则对联合训练的所有入口同时生效：before/after、正负文本、其他可见对象、图标签、正控制、状态补充数据和辅助任务。两个关系保留类型对均为 cube–cylinder，而绑定只用目标形状–sphere，可避免绑定数据自然泄漏，但仍由程序审计。若某保留组合经其他入口出现，只能改称相应任务监督留出，不能继续称整个适配训练未见。

预实验数据视为开发数据，其图片不再重新划成主实验正式测试图片。主实验测试使用新场景，清单、候选、划分及哈希在训练前固定；在开发期间不据正式测试表现修改模型和损失。预训练模型历史不受本划分控制，“未见”仅指本研究所定义的适配训练范围。

正式生成前交付：允许状态组合表、合法编辑边表、逆关系等价类表、跨所有训练入口的泄漏检查，以及各划分的原子/组合/转换/独立场景覆盖统计。检查空转换、逆向重复和同家族跨区。首版仅覆盖少量预设保留组合：绑定 OOD 测试只有 2 个转换，关系 OOD 测试只有 1 个类型对，宏平均只是对 2 个或 1 个值求平均，结果可能来自具体组合的特殊性。增加同一组合的渲染数量不能代替更多组合；颜色分组和类型对轮换列为预算内优先项，是否纳入在正式训练前固定，结论中必须写明具体保留的转换与类型对，不使用未限定范围的“组合泛化”表述；预算不允许轮换时，结论限定于当前保留组合。

主实验训练量按开发集学习曲线、可行组合覆盖和总资源上限确定；每转换 300–500 场景仅可作为候选预算，不作为最低充分样本数。正式测试量按希望区分的配对效应、方法分歧与场景相关性另行估计，并与训练量分开登记。第二阶段末给出训练/验证/测试的目标值、最低覆盖要求、允许上限和预计生成时长，冻结后生成；不为追求显著结果反复增加已查看的正式测试集。

**9.4 固定主指标、模型选择和统计口径。**

主指标固定为“组合 OOD 测试集上的 I2T Pair Accuracy 宏平均”。模板 t、任务 k、转换 r、独立场景 s 的配对正确值为 `b_k,r,s,t = 1[S00>S01 且 S11>S10]`，平局记错；按以下顺序汇总：

`a_k,r,s = mean_t(b_k,r,s,t)`

`A_k = mean_r(mean_s(a_k,r,s))`

`A_main = mean_k(A_k)`

因此任务先等权、任务内转换再等权，每场景的七模板不增加独立样本数，逆向重复不增加场景或转换权重。各任务均单独报告，整体平均改善不能代替“两项任务均改善”的证据。除宏平均外，逐转换、逐类型对报告点估计与区间，并列出所用保留组合清单。bootstrap 在任务/转换覆盖固定的条件下按基础场景家族重采样，并重新计算同一宏平均；同家族跨多个指标时共享重采样权重，不以普通 item 加权均值替代。区间条件于当前保留组合，不能推广为所有可能组合的区间。

单图 I2T、T2I、逐任务/组合、IID 测试及身份/颜色保持为辅助指标；E4 给定指令的 after 检索仍是机制指标。验证选模使用相同任务宏平均的 OOD 验证 Pair Accuracy，并在预先指定的 IID/保持性容忍范围内选择；容忍值和超参数搜索表只依据开发数据制定，在正式训练前固定。

主归因是所有方法在同一 OOD 测试集上的配对差异。IID/OOD 比较尽量匹配共同支撑的颜色、形状、材质、布局及候选难度边际；保留组合本身不能完全配平，不把两组绝对难度差单独解释为组合因果效应。冻结候选、模板、负例及 checkpoint 选择规则；正式测试不参与任何方法或损失选择。

主实验至少安排 3 个训练随机种子，固定数据划分，报告训练种子差异与场景聚类配对区间，不把种子乘图片数作为独立样本数。主要比较对象在验证阶段预先指定；多项确认性比较使用同一冻结的校正规则。机制复测使用第 4 节禁止训练/选模的清单；训练前后在相同探针划分上分别重训同容量、同搜索预算的探针，并保持参考方向估计数据角色一致。该集已用于第二阶段诊断，前后复测仅作辅助解释，不冒充新的独立确认测试；主实验新封存集可额外报告相同机制指标。

**9.5 固定能区分各项贡献的基线表。**

| 方法 | 要检验的问题 |
|---|---|
| 冻结原模型 | 相对原始表示是否改善 |
| 普通状态匹配适配 | 是否仅来自额外训练与参数 |
| 同适配层加 hard negatives | 是否仅来自反事实困难负例 |
| 相同 2×2 样本的配对排序目标 | 是否仅来自成对状态分数差或等价 delta 目标；固定对应 L_pair/C 控制 |
| 状态级图结构监督 | 是否仅来自场景图监督，而无需变化建模 |
| 不依赖上下文的编辑变换训练 | 是否需要上下文相关变换；使用与主模型相同的普通匹配推理接口 |
| 同编辑信息的平坦编码/同容量无图结构版本 | 是否需要图结构组织，而不仅是获得额外的编辑标签 |
| 完整 GraphDelta 及去掉变化对齐/上下文的消融 | 对齐目标和上下文模块各有什么贡献 |

基线损失和完整模型使用同一多正例真值及表示接口。普通适配使用 L_state 与相同锚定设置；hard-negative 版本增加相同难负例；配对版本明确增加 L_pair；固定变换版本的预测器只读 edit，不读 context。完整模型与平坦编码版本保持编辑语义信息相同；去对齐/去上下文消融只改变指定项。若 L_align 的收益可由 C/范数分解控制解释，应如实收缩机制结论。

逐方法记录图像、文本、额外监督、负例、参数量、数据暴露量、步数、GPU 小时及调参次数。冻结原模型、普通适配、hard-negative 和配对目标四个基线是判断主线所必需，不因工期裁剪；“同编辑信息的平坦编码”及 ViT-B/32 扩展在人力不足时可后移，后移决定在正式训练前记录。公平性主要按相同训练数据暴露量、匹配适配层和选模预算控制，辅助头额外容量与实际计算成本单列；不要求步数、GPU 小时和参数量同时严格相等。主实验执行这些基线，不要求第二阶段先获得其性能结论。

**9.6 主实验第 0 步执行小样本训练联调。**

使用开发集约 50–200 对、几十至几百步，检查：损失有限；预期参数有梯度，冻结参数不更新；单独开启变化损失影响实际匹配适配层；stop-gradient 符合第 9.2 节；保存加载后分数一致；移除辅助头与图输入后匹配可执行；identity 适配层与原评分在约定误差内一致。同时检查多正例掩码、真假负例、近零 delta 和表示坍塌监测，确保零变化/只读 edit 的策略没有被误当作目标机制。

所有主实验方法至少跑通同一数据加载、checkpoint 和评测接口。此步骤不检验统计提升、不接触封存测试、不增加一轮预实验，也不以总损失下降代替梯度路径核验。若联调失败则修实现，不能直接扩大训练。第 0 步安排在第二阶段交付训练实现之后、主实验核心训练启动之前，作为训练实现交付物的验收步骤；使用第二阶段开发数据，不构成新的预实验轮次。

联调样本同样通过第 9.3 节的全入口审计，仅使用训练允许组合，禁止 OOD 验证/测试组合及第 4 节留出机制集。联调 checkpoint 不作为正式训练初始化；各方法、各训练种子从协议规定的干净初始化重新开始，初始化来源和种子写入运行记录。

**9.7 第二阶段的最终交付与主实验入口。**

结束时交付四项：受控数据与质量报告；绑定/关系诊断及证据边界；版本化主实验配置、合法编辑/封存清单；训练实现与资源预算。预算必须有实测依据，列出开发人日、每方法每骨干的 GPU 小时/步数/数据暴露量上限、渲染与重试时长、图片/缓存/场景文件磁盘量，以及调参与失败重跑余量。仅六个需训练版本×两个骨干×三个种子就有 36 次运行；这是成本示例，实际次数按最终基线与消融矩阵逐项枚举，不能遗漏。

执行顺序固定为：环境与原图审计 → 合法编辑枚举和小批渲染 → 冻结 E4 配置、生成诊断数据 → 完成两任务诊断及训练实现 → 结束预实验 → 主实验第 0 步联调 → 核心方法/基线 → 消融与预定扩展。正式 E4 前验收统计与数据协议，主实验批量生成前验收合法组合和资源预算，正式训练前验收损失与梯度路径。尚无实测值的成本字段先标记“待试运行测量”，作为执行任务补齐，不编造数字，也不增加新的预实验轮次。
