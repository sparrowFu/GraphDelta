## 总体判断

本轮结果对“冻结 CLIP 的状态级结构区分存在不均衡”提供了明确支持，对“单因素变化响应具有可重复规律”提供了部分支持；没有检出预期的 CoGenT A/B 整体难度不对称。按预实验方案分类，更接近 §71 的情况 C，同时保留 E1 与部分 E2 正证据。

建议修正评估问题并做小规模 Controlled Edit 机制验证，暂不直接进入完整 GraphDelta 训练。现有结果不能证明结构识别不足由 Delta 响应不足造成，也没有验证视觉与文本的结构变化是否对齐或能否迁移到未见组合。

## 1. 结果完整性与统计口径

- E1：10 个 dataset×factor 单元，每单元 2,000 个样本，共 20,000 条题目。独立核对 JSONL 后，各单元都有 2,000 个不同 image_id，没有正负文本完全相同的题目。
- E2：103,440 个变化 pair。environment 为 13,440，其余三因素各 30,000；共覆盖 2,031 种 transition，没有低于两个 context 的 transition。
- E3：A/B×cube_cylinder/sphere 四单元各 3,000 条题目，共 12,000 条。题目数不等于独立图片数。
- E1/E3 的 accuracy 是先在每个模板下判断正负，再平均七个固定模板的正确率。不是文本特征先集成后的一次判断，也不能把七倍预测当作独立观测。CI 按图片 bootstrap，模板集合固定。
- E2 的 `z` 表示 L2 归一化特征空间，不是 z-score 标准化。raw 表示投影后、归一化前空间。
- 配置列出 seeds=[0,1,2]，但各脚本一次只使用一个采样 seed。现有输出没有多次运行汇总、seed 列或模型版本列，不能称为三 seed 稳定结果。默认生成路径固定，重新运行会覆盖同名结果。

CLEVR 中颜色比关系高 **15.98 个百分点**，差值 CI 为 **[13.28,18.94]**；颜色比绑定高 **16.81 个百分点**，CI 为 **[14.09,19.53]**。这两项是最强、解释最直接的状态级证据。object 比 binding 高 5.32pp，CI [2.50,8.16]。

应限定为“颜色明显强于关系／绑定，对象识别也有一定优势”。size 与 relation/binding 的差值 CI 均含零，不能说所有属性任务都明显更强。relation、binding 各自的 CI 都覆盖 50%，宜写“接近二选一随机水平”，不能写“显著低于随机”或“完全没有关系／绑定信息”。不同题型的文本长度、所需对象数量和负例构成也不同，factor gap 是当前诊断任务差异，不是能力差异的唯一因果解释。

### SPAR 有需要重跑的样本构造问题

代码仅用 `character2_name != "blank"` 判断双对象，没有对称排除第一个槽位为空的情况，导致把空对象占位符当成动物。

| 因素 | 正例含 `blank` | 占该组比例 |
|---|---:|---:|
| scene | 64/2000 | 3.2% |
| position | 62/2000 | 3.1% |
| attribute | 68/2000 | 3.4% |
| relation | 62/2000 | 3.1% |

例如 `the blank is to the left of the Crow`、`a blue blank and a red Elephant`。因此当前 SPAR 自建数字应标为待修正结果。双对象任务应要求两个槽位都非 blank；scene 应根据实际存在的对象生成描述，并单独处理空背景。

不过，这个问题解释不了全部低于随机：即使 62 条污染题全部答错，删除后 position、relation 的点估计最高也只有 41.10% 和 48.12%。还需检查语言／模板／方向偏置。现有 position 正例 left=1504、below=496，relation 为 left=1507、below=493，缺少反向正例平衡。position 的跨模板准确率标准差达 **6.85pp**，明显高于 CLEVR 各项的 0.15–0.62pp。不能直接把低分解释成“空间理解方向反转”。

另需澄清：`scene` 的负例保持环境不变，替换动物名称，实际测对象存在性／身份区分。89.66% 不应被描述为背景识别准确率。

证据：[双对象判定](D:/code/GraphDelta/code/src/experiments/e1_state_diagnosis.py:157)、[实际题目](D:/code/GraphDelta/code/outputs/tables/e1_items_spar.jsonl:3939)、[scene caption](D:/code/GraphDelta/code/src/data/captions.py:62)。

## 3. E2：变化规律存在，但强弱高度不均衡

| 因素 | 同 transition 跨 context 余弦 | Transition Gap，95% CI | raw 范数／视觉 nuisance | raw 范数差，95% CI |
|---|---:|---:|---:|---:|
| environment | 0.6433 | 0.6426 [0.6381,0.6474] | 2.481× | 7.6748 [7.6139,7.7289] |
| texture | 0.1155 | 0.1134 [0.1095,0.1171] | 0.996× | −0.0221 [−0.0725,0.0241] |
| size | 0.0548 | 0.0504 [0.0470,0.0537] | 0.931× | −0.3594 [−0.4085,−0.3100] |
| camera | 0.0153 | 0.0172 [0.0142,0.0202] | 1.405× | 2.0973 [2.0510,2.1463] |

Transition Gap 定义为“同 transition、异 context 相似度 − 异 factor、异 context 相似度”。四项 CI 都高于零，但统计可检出不代表效应都强。

- **environment：明确的正结果。** 同一具体环境切换在不同 context 中方向较一致，幅度也明显大于当前 nuisance。它首先说明大范围场景变化有稳定信号，尚未验证关系或绑定编辑。
- **texture：有一定方向重复性，幅度约等于 nuisance。** 不能说已经获得清晰、抗扰动的语义变化表示。
- **size：响应幅度小于当前 nuisance，跨 context 一致性也弱。** 同 transition 相似度 0.0548 与同 factor、不同 transition、异 context 的 0.0507 很接近，现有正 Gap 不能证明模型特别区分了具体 size transition。
- **camera：变化幅度大，跨 context 方向几乎不一致。** 0.0153 的绝对相似度很小，不能仅凭 Gap CI 大于零就称为稳定变化表示。

raw 与归一化空间的趋势一致，四因素 Transition Gap 的最大绝对差约 0.000602。当前结论并非只出现在某一种归一化口径。

同 context、不同 transition 的相似度，texture/size/camera 分别为 0.1743/0.4027/0.1493，高于同 transition 跨 context 的 0.1155/0.0548/0.0153，提示较强 context 依赖。但同 context 的 pair 可能共享端点，这也会造成代数相关性，不能把差值全部归因为语义 context 效应。

来源：[E2 主表](D:/code/GraphDelta/code/outputs/tables/e2_delta_stats.csv)、[分组实现](D:/code/GraphDelta/code/src/metrics/delta_stats.py:98)。

### nuisance 定义需要先复核

增强函数注释写裁剪“面积比例”，实际把 0.85–1.0 同时乘在宽、高上，对应保留面积约 **72.25%–100%**，随后叠加 JPEG 90/75。裁剪再缩放可能改变对象可见性与相对尺度，因此并不天然是对 size 语义完全无影响的轻扰动。

当前能得出的结论是“size 响应低于这一具体增强基线”，不能直接推导“模型对大小没有语义响应”。建议分开跑 JPEG-only 和真正面积保留 85%–100% 的 crop 对照。若面积是设计意图，应将采样比例开平方后作用于边长。

证据：[增强实现](D:/code/GraphDelta/code/src/features/delta.py:13)、[配置](D:/code/GraphDelta/code/configs/e2_change.yaml:19)。

### 覆盖充分不等于每个 transition 估计都稳定

environment 的 2,016 种 transition 全覆盖，但每种只有 3–11 个 context（中位数 7）；逐 transition 相似度 0.1406–0.8543，没有单组 CI，不宜按极值做稳定性排名。其他因素每种 transition 约 5,000 或 10,000 个 context，样本密度很不一样。

补充统计边界：

1. same-transition 比较的采样对允许重复，不是完全枚举独立对；环境每组 context 很少，直接枚举更清晰。
2. 每 transition 至少尝试 32 次、再受组合数限制，没有最终全组截断。由当前 context 数可算出 environment 共有 38,791 次 same-transition 比较，超过配置名称暗示的 20,000；不同 transition 的权重也不严格相等。当前宏平均 transition 相似度约 0.64326，与主表 0.64334 接近，未见总体趋势由该权重问题主导。
3. factor/nuisance Norm Gap 两侧分别使用 context 字符串与 image_id 聚类，没有联动恢复同一原图同时参与两侧时的依赖。现有 CI 已处理因素侧的 context 相关性，跨组共享原图部分仍建议做敏感性核对。

来源：[逐 transition 表](D:/code/GraphDelta/code/outputs/tables/e2_transition_stats.csv)、[比较采样](D:/code/GraphDelta/code/src/metrics/delta_stats.py:40)、[transition 汇总](D:/code/GraphDelta/code/src/metrics/delta_stats.py:178)、[Norm Gap 聚类](D:/code/GraphDelta/code/src/experiments/e2_change_diagnosis.py:221)。

## 4. E3：没有整体 A/B 不对称，形状细分更有信息

**换形题 cube 与 cylinder 相差约 55pp，且 A/B 都有同样模式。** 每种颜色在两个条件间对应不同形状，逐色换形结果也都是 cube 高于 cylinder。蓝色汇总 A 85.07%、B 45.81%；红色 A 25.44%、B 79.56%；黄色 A 94.25%、B 50.82%。因此整体 A/B 接近可能掩盖了相反方向的组合差异，不能只看总均值。

最合适的现阶段表述是“存在稳定的形状相关难度与负例构成差异的迹象”。尚不能直接断定 CLIP 具有单纯的 cube 文本偏好：负形状从同色且整图不存在的形状里随机抽取，另一种 cube/cylinder 在该条件必不存在，但 sphere 是否可选取依赖场景。没有逐题的 neg_shape，就无法分离 cylinder→cube 与 cylinder→sphere。

sphere 约 74%，并未达到明显天花板；同时 sphere 换形题的负例分布也受颜色调色板影响，因此不是完全隔离所有混淆的对照。

现有输出仅保存聚合表，没有 E3 的 image_id、具体负例、逐模板正确性／margin。上述细分是描述性重构，无法从当前文件给形状子组补上按图聚类的 CI。还应抽查输入经 CLIP 预处理裁剪后，整图 scene annotation 指向的对象是否仍然可见；当前没有图像和处理后视图，尚不能确认这一风险是否实际发生。

## 5. 下一轮工作的优先级

1. **先修评估有效性。** 对称处理 SPAR 两个对象槽位的 blank，明确 scene 的真实任务名称；复核 nuisance 的面积／边长定义，拆分 JPEG-only 与 crop 对照。重跑受影响项，保留本轮输出作为对照。
2. **保存可复查的逐题结果。** E1/E3 保存 image_id、正负文本、负例具体值、每模板分数和正确性；E2 保存配对与比较索引。记录 model/checkpoint、seed、配置、代码 commit，输出到独立 run 目录。
3. **补采样稳定性。** 分别运行 seed 0/1/2，不覆盖旧结果；报告每次结果与跨 seed 范围。bootstrap 次数不是独立实验次数。随后用第二个冻结 baseline 复核少数关键项，再决定能否推广到其他模型。
4. **控制负例与方向构成。** SPAR 正例包含两种叙述方向，按水平／垂直与模板分层。E3 固定 cube→cylinder、cylinder→cube，单列与 sphere 的配对；保持颜色、正例形状和 negative_type 配比一致，再看形状差与 A/B 交互。
5. **开展小规模第二阶段机制验证。** 优先选关系反转、绑定交换等受控编辑，检验视觉 Delta 是否响应、文本 Delta 是否对齐，以及跨 context 是否可迁移。不要只用最强的背景变化信号代替结构编辑证据。

建议用于阶段总结的表述：

> 冻结 CLIP 在当前评估中表现出明显的结构区分不均衡，颜色识别优于关系与绑定判断。单因素响应的可重复性高度依赖因素，环境变化最强，纹理、尺度和相机变化的幅度或跨 context 一致性有限。本轮未检出 CoGenT A/B 的整体难度不对称，但发现跨条件稳定的形状相关难度。结果支持修正评估后进一步开展受控结构编辑机制验证，尚不足以证明跨模态结构变化迁移或 GraphDelta 方法有效。
